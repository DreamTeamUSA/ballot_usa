# Policy

We are converting Ballot into a civic issue tracking system.

## Core Entities

- Users (citizens, officials)

- Issues (replaces posts)

- Representatives

- Districts

- Subscriptions (replaces follows)

## Core Flow

1. User enters location

2. System identifies district + representatives

3. User submits civic issue

4. Community supports issue

5. Representative responds

6. Status is tracked publicly

## Goal

Turn social feed into civic accountability system.
